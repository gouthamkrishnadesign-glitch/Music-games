# Music Games

**Note Friends**: a playful, dark-mode piano theory course for young children (ages 5–7).

- 45 lessons, including a Count & Play unit (count out loud, count & hold every note, the beat map, count-then-play, tap the rhythm): note names, sharps and flats, half and whole steps, octaves, posture, the staff, ledger lines, landmark notes, treble and bass clefs, note lengths, eighth notes, dotted notes, fruit rhythms, rests, time signatures, ties, slurs, staccato, accents, fermatas, dynamics, tempo, repeats, a memory game, and 7 real songs
- Quiz Zone with 19 games, stars, streaks and trophies
- Teacher notes on every topic

Open `index.html` in a browser, or visit the GitHub Pages site.
