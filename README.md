# Music Games

**Note Friends**: a playful, dark-mode piano theory course for young children (ages 5–7).

- 50 lessons, including a High, Middle & Low C unit (the C family, registers, staff-to-piano mirror, a note map of every note in every register, octave jumps) and a Count & Play unit (count out loud, count & hold every note, the beat map, count-then-play, tap the rhythm): note names, sharps and flats, half and whole steps, octaves, posture, the staff, ledger lines, landmark notes, treble and bass clefs, note lengths, eighth notes, dotted notes, fruit rhythms, rests, time signatures, ties, slurs, staccato, accents, fermatas, dynamics, tempo, repeats, a memory game, and 7 real songs
- Quiz Zone with 24 games, stars, streaks and trophies
- Teacher notes on every topic

Open `index.html` in a browser, or visit the GitHub Pages site.
